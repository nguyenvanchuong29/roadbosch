⚠️

Read before starting — Philosophy / Đọc trước khi bắt đầu

Depth over breadth. Each phase must be understood well enough to explain to someone else before moving on. Bosch does not need people who know many things shallowly — they need people who understand C deeply, know how an ECU truly works, and can contribute from day one of internship. One well-done project on GitHub is worth more than 10 Udemy certificates.
Chiều sâu hơn chiều rộng. Mỗi phase phải nắm chắc đến mức giải thích được cho người khác mới chuyển tiếp.


English from day one. All code comments, variable names, README files, and commit messages must be written in English. Bosch BGSV works entirely in English. Start this habit now, not later.
Tiếng Anh từ ngày đầu. Mọi comment, tên biến, README, commit message phải viết bằng tiếng Anh. Bosch làm việc hoàn toàn bằng tiếng Anh.


Testing is not the last step. Based on real Bosch job postings, testing (unit, integration, SIL, HIL) is core work at BGSV — not a final phase. Write tests from Phase 1 onward.
Testing không phải bước cuối. Theo job posting thực tế tại Bosch BGSV, testing là công việc cốt lõi — không phải giai đoạn cuối. Viết test từ Phase 1.

⚡ Bosch BGSV Vietnam — What you need to know / Điều cần biết

Bosch Global Software Technologies Vietnam (BGSV) in HCMC is a software development center, not manufacturing. The embedded team does BSW generation, AUTOSAR workflow, acceptance testing of third-party software modules, and software validation. They look for people who can read specs, write clean code, write tests, and communicate in English.
BGSV HCMC là trung tâm phát triển phần mềm. Team embedded làm BSW generation, AUTOSAR workflow, acceptance testing, và software validation. Họ tìm người biết đọc spec, code sạch, viết test, và giao tiếp tiếng Anh.

🎯 Project-based learning / Học theo dự án

Học theo dự án, không theo topic

Don't study C then MCU then CAN separately. Start projects early, learn what the project needs. You'll remember 10× more than reading books alone. / Bắt đầu project sớm, học những gì project cần.

📖 Read datasheets — daily habit / Đọc datasheet hàng ngày

Tập đọc datasheet và spec từ sớm

Bosch engineers read Reference Manuals every day. Get comfortable with 1000-page PDFs. Practice: don't use tutorials — read the datasheet and code from it. / Kỹ sư Bosch đọc Reference Manual hàng ngày.

🧹 Code quality > code quantity / Chất lượng hơn số lượng

1 project sạch hơn 10 project copy-paste

1 clean project with tests and English README beats 10 copy-paste projects. MISRA-C exists for safety, not to punish — apply it. / MISRA-C không phải để hành mà để code an toàn.

🔌 Use real hardware early / Dùng hardware thật sớm

Simulator không dạy troubleshoot

Simulators don't teach you to troubleshoot. Buy an STM32 Nucleo, wire it up, debug real hardware — those are the skills needed on day 1 of internship. / Mua STM32, nối dây, debug hardware thật.

🐍 Python is a tool, not optional / Python không phải tùy chọn

Bosch dùng Python cho test automation hàng ngày

Bosch uses Python daily for test automation, CAN data analysis, and scripting. You already have Python installed. Use python-can from Phase 3 onward. / Bosch dùng Python mỗi ngày cho test automation.

🌐 English from day one / Tiếng Anh từ ngày đầu

Mọi thứ ở Bosch bằng tiếng Anh

Every variable name, comment, commit message, README, and Bosch meeting is in English. Build the habit now. Writing in English = communicating at Bosch. / Mọi comment, commit message, README phải bằng tiếng Anh.
